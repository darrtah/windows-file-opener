# Windows File Opener for OpenCode Desktop

Независимый локальный плагин для OpenCode Desktop на Windows. При нажатии на поддерживаемую ссылку на файл в сообщении предлагает открыть файл в программе Windows по умолчанию, показать его в Проводнике или отменить действие.

Поддерживаются распространённые изображения, видео, PDF и документы Office/OpenDocument. Ссылки на сайты, исполняемые файлы и сетевые пути плагин не перехватывает. Файлы должны существовать на том же компьютере, где работает OpenCode Desktop. Относительные ссылки работают только если OpenCode передаёт путь текущей сессии.

## Установка на другом ПК

Нужны Windows, OpenCode Desktop и доступ к этому приватному GitHub-репозиторию из Git на компьютере. Установите плагин командой:

```powershell
opencode plugin add 'git+https://github.com/darrtah/windows-file-opener.git#v0.1.0' --global
```

Git может запросить авторизацию для чтения приватного репозитория. Не вставляйте токены в URL или настройки OpenCode. Плагин загружается в Desktop; после установки нажмите ссылку на локальный PDF, изображение или видео и проверьте меню. Если GUI отключён, проверьте **Settings → Extensions → Plugins**.

Проверено пользователем на Windows с OpenCode Desktop 2.2.7. GUI API OpenCode экспериментальный и может меняться. Плагин не добавляет пункт в контекстное меню по правой кнопке.

## Разработка

Для сборки нужны Node.js и npm:

```powershell
npm install
npm test
npm run build
```

Собранный `gui-experimental.cjs` включён в репозиторий для установки из Git. В `vite.config.js` выключена очистка каталога сборки, чтобы не удалить исходники.
